# sklarstad.com

Source for https://sklarstad.com (served by GitHub Pages from sklarstad/sklarstad.github.io) — the Sklarstad company site and the FirstTake product page.
Static HTML/CSS, no build step. Agent-facing files: `llms.txt`, `llms-full.txt`, `products.json`
(a copy of the storefront MCP server's public catalog), `robots.txt`, `sitemap.xml`.

At FirstTake's launch, follow the LAUNCH SWITCH comment in `firsttake/index.html`, update the
availability wording in `llms.txt` / `llms-full.txt`, and refresh `products.json` from the
storefront catalog.
